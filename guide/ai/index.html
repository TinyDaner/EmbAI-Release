    AI 助手¶

    右侧常驻面板，Ctrl+J 开关。切换视图不会中断对话。

    它不是一个只会聊天的框：约 130 个工具让它能真的读写文件、编译烧录、下断点单步、 读寄存器、配引脚、查 Git。

    选模型¶

    设置 → AI 模型，分两组：

    系统内置¶

    开箱即用，不用自己申请 API Key。走 EmbAI 云端，按积分计费， 每个模型旁边标着单价（形如 0.9 / 2.7 分·千tok，分别是输入和输出）。

    积分怎么算、怎么充，见账户与积分。

    我的模型¶

    填自己的服务地址和 API Key，直连厂商，不消耗 EmbAI 积分。

    支持的厂商：Anthropic、OpenAI、通义千问、智谱 GLM、MiniMax、Kimi（Moonshot）、 DeepSeek，以及自定义。接口形态可选 responses、chat_completions、anthropic_messages 三种。

    API Key 按账号加密保存。

    两组可以并存

    日常用内置的省事，跑长任务时切到自己的 Key 更划算 —— 在输入框下方工具条的模型选择器 （发送按钮左边、显示当前模型名的那颗）里随时切。

    Plan 模式¶

    让 AI 先交计划、等你批准，再动手。适合改动面大、不想让它直接开干的场合。

    三种开法：

    • 输入框左侧 + → 计划模式
    • 输入 /plan 你的任务
    • Ctrl+Alt+P

    开启后输入框会有蓝色描边和灯泡标记。

    AI 会先产出一份 Markdown 计划卡片，你可以：

    操作 效果
    批准 开始按计划执行
    退回修改 附上你的意见，让它改计划
    拒绝 否掉这个计划
    取消 中止

    执行过程中卡片状态会跟着走（进行中 / 已完成 / 未完成等）。

    面板标题栏的 ⋯ → 计划历史与模板，可以回看历次计划、把好用的存成模板复用， 也能对计划做检查点和回滚。

    审批模式¶

    输入框上的盾牌图标，决定 AI 动手前要不要问你：

    模式 行为
    请求批准 写文件和危险操作一律先问
    替我审批（默认） 只有被判定为有风险的操作才问
    完全访问权限 不再询问，可直接改工程文件、执行烧录（切换时会二次确认）

    另外设置 → AI 模型里还有一组按类别的工具权限开关：文件操作、编译构建、调试控制、 内存操作、追踪分析、硬件控制、MCU 配置（外设与寄存器读写归在这一类）、SDK 管理、 虚拟硬件、工具链、原理图、Datasheet、提升到硬件，另有几类暂未汉化、按英文键名显示 （standard / knowledge / search / symbol / git / dashboard）。整类关掉后 AI 就用不了那类工具。

    这份清单由后端动态下发，新增分类会自动出现在设置里。

    给 AI 喂上下文¶

    附件¶

    输入框左侧 + → 添加：

    • 文件 —— 从工程树里挑
    • 选中的代码 —— 编辑器里选中的那段
    • 编译错误 —— 直接把构建输出里的报错带上
    • 图片 —— 截图、实物照片、波形照片都行

    @ 引用¶

    输入 @ 触发补全：

    • @schematic:文件名 —— 引用已分析的原理图
    • @datasheet:文件名 —— 引用已索引的 Datasheet

    比如「按 @schematic:主板v2 上的接法初始化 SPI2」。

    斜杠命令¶

    命令 作用
    /plan <任务> 以 Plan 模式开始
    /template 使用计划模板
    /explain 解释选中或指定的代码
    /fix 修复问题
    /build 让 AI 分析构建配置并给出建议（不等于工具栏的构建）
    /flash 烧录
    /register <名> 查某个寄存器
    /peripheral <名> 查某个外设
    /hal <名> 生成该外设的 HAL 驱动代码

    AI 反问你¶

    遇到需求不明确时，AI 会主动提问并给出 2–4 个候选项让你点选，而不是自己瞎猜。 新建工程后的代码生成就大量用到这个 —— 它会一项项确认你要什么。

    会话管理¶

    操作 说明
    新建会话 Ctrl+L
    停止当前回答 Esc
    聚焦输入框 Ctrl+K
    归档 / 取回 会话列表底部切换「显示已归档任务」
    分叉 从任务当前进度复制出一条新线继续，原任务完整保留（不能选某条历史消息作分叉点）
    回退 退回到之前某个状态重来
    压缩上下文 对话太长时把前文压缩成摘要，腾出上下文空间
    复制为 Markdown 整段对话导出，方便贴到别处

    对话在后台继续跑 —— 关掉面板或切走视图都不会中断，回来还能看到完整过程。

    网络搜索¶

    设置 → AI 模型 → 网络搜索里配置搜索服务和 Key 之后，AI 才能联网查资料。 没配的话它不会联网，其他功能不受影响。

    用法建议¶

    • 改动大先用 Plan 模式：看一眼计划比事后回滚便宜
    • 报错直接甩给它：+ → 编译错误，比自己复述准确
    • 原理图先传上去：之后所有涉及引脚的对话都能少解释很多
    • 长任务盯一眼积分：内置模型是按 token 计费的，见账户与积分
