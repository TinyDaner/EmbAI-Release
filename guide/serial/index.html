    串口与超级串口¶

    EmbAI 有两套串口界面，用途不同：

    用途
    串口助手（底部面板） 收发文本、看日志、发调试命令
    超级串口（活动栏） 把串口里的数值实时画成波形和仪表

    串口助手¶

    底部面板 → 串口助手。或点工具栏右侧的 Serial 状态灯直接连断。

    连接参数¶

    参数 可选值
    波特率 下拉选择，1200 – 4000000 共 22 个固定档位（默认 115200），不支持自填
    数据位 5 / 6 / 7 / 8
    停止位 1 / 1.5 / 2
    校验 无 / 奇校验 / 偶校验
    打开时复位 勾选后打开串口即复位目标

    功能¶

    • HEX 视图 —— 按十六进制显示收到的字节
    • 时间戳 —— 每行前加上到达时间
    • 收发字节计数 —— 实时统计 RX / TX
    • 中文乱码重解码 —— 固件按 GBK 输出中文时可以正确还原
    • 历史记录 —— 发过的命令可以翻出来重发

    超级串口¶

    活动栏 → 串口 → 超级串口。

    这是一个可拖拽的仪表盘：把串口里的数值绑到控件上，实时显示。

    控件¶

    控件 用途
    波形图 一个或多个通道的时序曲线
    仪表 圆形指针表
    数值 大字号数显
    指示灯 布尔量状态
    滑杆 拖动向下位机发送数值
    按钮 点击发送预设命令
    终端 面板内嵌的文本收发

    工具栏上有添加控件、协议/通道、编辑布局（拖拽与缩放）、导出 CSV。

    布局保存在工程目录的 .embai/dashboard.json 里，可以随工程进版本库。

    数据协议¶

    协议 说明
    FireWater 文本格式，name:value 形式
    JustFloat 二进制浮点帧，带帧尾
    RawData 原始字节，自行约定
    无 不解析

    自动嗅探¶

    连上串口后，EmbAI 会尝试识别数据格式。识别出来时顶部会出现一条横幅， 形如「检测到疑似 X 协议（N 通道，置信度 M%）」，可以应用或忽略。

    这一步省掉了手动数通道的麻烦 —— 大多数情况下点「应用」就能直接出波形。

    典型用法¶

    1. 固件里按 JustFloat 或 FireWater 格式往串口发几个变量
    2. 打开超级串口，连接，等自动嗅探横幅出现后点应用
    3. 添加控件 → 波形图 → 绑定通道
    4. 需要在线调参就加一个滑杆，把值发回下位机
    5. 要留证据就导出 CSV

    与 AI 配合¶

    AI 可以直接操作串口和仪表盘：

    • 「连一下串口，115200」
    • 「加一个波形图显示通道 1 和通道 2」
    • 「把最近的串口输出读出来分析一下」
