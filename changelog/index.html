    Changelog¶

    v0.1.82 (2026-07-27)¶

    Features¶

    • 文档站重做，并新增英文版：此前发布的 8 篇文档是初版时写的，之后三个多月一直没跟着产品走 —— 里面写的是「用 CMake + Ninja + arm-gcc 编译、跨 Windows/macOS/Linux、克隆源码自己跑、本地填 API Key」，而实际上 EmbAI 是 Windows 桌面应用、固件只由 Keil MDK 编译、装的是安装包、走云端账户。另外还有一批代码里根本不存在的东西（EMBAI_PORT 环境变量、~/.embai/settings.json、六个不存在的 AI 工具名、三个不存在的脚本），以及互相矛盾的接口路径。现在全部按代码重写：新增按功能分的九章使用指南（工程管理 / 编辑器 / 编译与烧录 / 调试 / 串口与超级串口 / AI 助手 / 虚拟显示屏 / 原理图与知识库 / 账户与积分），中文在原地址、英文在 /en/，站内可切换语言；配色与 logo 对齐 EmbAI 品牌。面向维护者的架构说明、开发指南与 API 参考已下架（内容早已失真，对使用者也没有价值），「帮助与反馈」面板里的文档卡片同步换成新的分章入口。

    Fixes¶

    • 修复「附加截图」截到的是反馈面板自己：截图取的是整个窗口，而此时「帮助与反馈」正以浮层盖在最上面（还带一层压暗遮罩），结果每张附图都是反馈面板 + 一片压暗的背景，用户真正想让人看的 AI 助手或编辑器状态全被挡住。现在截图瞬间会先把面板隐藏、截完立刻恢复，且已经写好的正文、勾选状态与诊断信息一个不丢。
    • 讲清楚 GitHub 那条路是「预填」不是「提交」：按钮原来写着「或到 GitHub 提 Issue」，紧挨着上面那个真会自动发出去的「提交反馈」，看起来是同一类动作；但 GitHub 不允许由应用代提 issue，这条路只能在浏览器里打开一个已经填好内容的表单，最后仍需你自己点 Submit。现在按钮文案与点击后的提示都说明了这一点。
    • 修复正文较长时点 GitHub 毫无反应：预填链接的长度上限原来按字数算，但中文在 URL 里要按 UTF-8 编码，一个汉字占 9 个字符 —— 1200 字的正文会生成 11,431 字符的链接，远超系统上限，浏览器根本不会打开，界面上也没有任何提示。现在按链接的实际长度截断（约 145 汉字以内不受影响），超长时只预填开头并提示完整内容仍在输入框里；打开失败也会明确报错，不再静默。
    • 截图失败时给出提示：此前截图出错既不显示原因也不留痕迹，点了像是什么都没发生。

    v0.1.81 (2026-07-25)¶

    Fixes¶

    • 「帮助与反馈」从界面原型变成真功能：此前面板里 12 个链接全是占位死链、视频教程的时长与播放量是编造的、「附加截图」只是个不传任何东西的开关，而点「提交反馈」只会显示「提交成功」，内容根本没有发出去。现在快速入门与文档链接指向真实的在线文档站；反馈会真正提交到云端并可在服务端查看，失败时给出具体原因并可改用 GitHub 提 Issue（不再假装成功）；「附加截图」会真的截取当前界面随反馈一起提交；提交前会先展示将附带的版本 / 系统 / 后端日志尾部，日志可自行选择不带。视频教程与 Discord 两个不存在的入口已移除。

    v0.1.80 (2026-07-25)¶

    Fixes¶

    • 修复 AI「委托探索」子任务的能力边界与超时控制：子代理现在固定只能用「列目录 / 搜索 / 读文件」三个工具，不会因为主程序新增了其它只读工具就悄悄扩权；启动、执行、取消与清理纳入统一的 5 分钟总预算，超时会返回已经探索到的部分结果而不是空手而归，收尾的中断与清理也拿得到独立的时间预算。委托探索本身不再被当成写操作记账，因此不会再占用写锁或触发「上一次写操作结果未知」的重试拦截。
    • 修复设置里出现关不掉的 AI 工具开关：工具开关列表只显示真正可由用户启用/禁用的工具，不再列出「提问 / 更新待办 / 退出计划模式」这三个由运行时直接提供、开关不生效的内置工具。
    • 修复提问卡片可能在回合被取消时丢失：AI 向你提问后若回合恰好在这一刻被取消，问题卡片现在仍会完整写入记录，刷新后依然能看到这条未回答的提问。

    v0.1.79 (2026-07-24)¶

    Fixes¶

    • 修复登录后重装 / 更新版本有时要重新登录才显示模型：当本机保存的登录令牌在冷启动时已过期，本地后端（信任本机模式）不会返回 401、前端因此不会自动刷新，但把过期令牌转发给云端拉取模型列表时被云端拒绝，导致模型列表为空、必须手动重新登录才恢复。现在启动时会先刷新过期令牌再拉取模型；令牌刷新成功后也会自动重拉模型列表；云端拉取失败时也会刷新令牌后重试——无需再手动重新登录。

    v0.1.78 (2026-07-24)¶

    Fixes¶

    • 修复打包版自定义模型「解密崩溃 → 不停重试 → 无法停止 → 重启也不行」：当本机加密密钥变动、导致已保存的自定义模型 API 密钥无法解密时，后端不再崩溃并连锁重试，而是明确提示「该模型的 API 密钥无法解密，请在设置里重新填写」；期间可正常切换模型、可停止回合。本机加密密钥在读取失败时不再被静默重新生成（那会孤儿化所有已存密钥）。AI 通道断开改为指数退避重连、多次失败后停手并给出「重试连接」按钮，不再固定 2 秒无限重连。

    v0.1.77 (2026-07-24)¶

    Features¶

    • Apple HIG 浅色主题:全局支持浅色 / 深色 / 跟随系统三种外观,可在设置里切换。编辑器(Monaco embai-light)、聊天代码块、工程可视化 SVG 等一并适配浅色;深色外观不受影响。
    • 超级串口面板:面向 MCU 串口调试的数据可视化 —— 从串口原始字节流实时解析波形数据,内置常见串口波形协议(FireWater / JustFloat)与自动探测,提供波形图 / 数值 / 仪表 / LED / 按钮 / 滑杆等控件,可手动编排,也能让 AI 一句话按固件的串口输出自动生成整块面板。

    v0.1.75 (2026-07-23)¶

    Fixes¶

    • 修复打包版新用户登录偶发「登录票据兑换失败: The user aborted a request.」:AI 运行时(Codex 边车)启动移出后端启动关键路径,改为后台非致命启动 —— 一次瞬时抖动不再拖垮整个后端、连累登录与账户接口;后端与 /health 即刻可用,AI 侧后台自重试、失败也按需懒加载。登录票据兑换加退避重试 + 更长超时,兜住后端刚启动的窗口。Codex 异常退出时其真实原因(如状态库锁争用)现会写入后端日志便于诊断。
    • 推理深度菜单列表限高可滚:选项过多时「超强」等不再被裁,菜单整体限高、可滚动。

    v0.1.74 (2026-07-22)¶

    Fixes¶

    • 内置 / GLM / 自定义模型不再弹「模型元数据未找到」运行时警告:AI 运行时发给 Codex 的查表用模型名统一改为目录内、支持工具、上下文上限更大的 slug(gpt-5.4);既保留工具下发、又消除每轮的 fallback 警告,长对话上下文(353k)也不再被截断。真实模型名仍在网关侧还原,路由与计费不变。
    • 软件更新弹窗内容超长时可滚动:弹窗整体限高、中间内容区可滚动,「当前版本更新说明」等不再被裁到视口外。

    v0.1.73 (2026-07-21)¶

    Fixes¶

    • 修复内置模型「没有可用工具」:AI 运行时改为给 Codex 发送它能识别的模型名(内置云端模型名 gpt-5.6-luna/sol/terra 等此前不在 Codex 模型目录里,导致工具被整体丢弃、请求 tools=0),AI 重新能读文件、跑工具;真实模型名在网关侧还原,路由与计费不受影响。
    • 修复自定义模型「保存 API 密钥失败(HTTP 500)」:桌面端为每台机器本地生成并注入加密密钥(此前发布版从不注入,导致加密报错),添加自己的模型不再 500。

    v0.1.72 (2026-07-21)¶

    Fixes¶

    • 多工具连续执行时面板不再闪烁:批间的轻思考行(「已思考 <1s」)一封口就折入活动胶囊,不再先作为独立行露在外面、等下一个工具来了才收进折叠。

    v0.1.71 (2026-07-21)¶

    Fixes¶

    • AI 运行时缺失时优雅回退:桌面开发版在打包用的 Codex 运行时尚未构建时,回退到 PATH 上的 codex,不再整轮在启动阶段就崩、导致内置与自建模型全部用不了。
    • 减弱动态(reduce-motion)偏好下 AI 面板的忙碌转圈不再冻住;工具执行中的图标改为真旋转。

    v0.1.70 (2026-07-21)¶

    Features¶

    • Plan 模式灯泡指示:composer 在 Plan 模式开启时显示灯泡标识,点击即可退出。

    Fixes¶

    • 回合级消息行改为真实块盒,步骤间距不再被吞;步骤分界间隔挪到「已思考」上方。

    v0.1.69 (2026-07-19)¶

    Features¶

    • AI 运行时切换到 Codex app-server:AI 助手底层从 LangChain 迁移到 Codex app-server 边车,回合更稳,工具调用与实时思考流式更贴近原生形态。
    • AI 面板重构:叙事流 + 活动行 + 回合摘要的原生形态,多轮对齐设计稿;任务支持重命名 / 置顶 / 归档,UI 名词统一为「任务」。
    • 系统内置云端模型:开箱即用的内置云端模型(gpt-5.6 luna / sol / terra 等),额度不足时弹出充值卡。
    • 环境信息面板:查看当前工作区与运行时等环境信息。

    v0.1.68 (2026-07-15)¶

    Features¶

    • 自动更新弹窗显示当前版本更新说明:打开「软件更新」弹窗即可看到当前运行版本的更新内容(changelog 随包分发、离线可用),不再只有检测到新版本时才有内容;有新版本时另外显示新版本的更新说明。更新说明改用 Markdown 渲染,标题 / 列表 / 引用结构清晰。

    v0.1.67 (2026-07-15)¶

    Performance¶

    • 冷启动渐进式可交互:启动壳 + 组件懒加载 + 启动状态机;后端重型服务(AI 运行时 / 知识库 / 符号索引)改懒初始化、AI 回合优先抢占,大项目启动更快、更早可操作。

    Fixes¶

    • AI 会话归属隔离:按用户严格隔离 AI 会话、切换用户彻底清理状态,防跨用户串话。
    • AI 通道进 IDE 即连接 + 首帧入队,回访用户不再断连 / 丢消息。
    • 恢复 Monaco 编辑器的查找 / 跳转定义 / 折叠 / 悬停 / 补全等功能。
    • 切 / 开工程同步清符号索引,消除旧工程结果的 5 秒窗口;后端崩溃不再被误报成 degraded。

    v0.1.66 (2026-07-15)¶

    Fixes¶

    • 中断 AI 任务后立刻发新消息不再被旧任务吞并:取消当前轮后马上发的新消息会开一个干净的新回合,不会被上一轮残留的续跑逻辑并吞。

    v0.1.65 (2026-07-15)¶

    Features¶

    • 串口助手:AI / 手动 / 快捷发送的命令统一回显:AI 通过工具下发的串口命令现在也显示在串口助手里(带「AI」来源徽标),不再只看到设备回复、不知是什么命令触发的。

    Changes¶

    • 串口助手对标通用串口助手的显示优化:TX / RX 双色方向标记、可开关的时间戳、HEX / ASCII 视图切换、UTF-8 / GBK 编码切换、长帧自动换行、RX / TX 字节计数;并改为串口连着就常连收集,切走标签也不丢数据。

    v0.1.64 (2026-07-15)¶

    Fixes¶

    • 待办执行完不再污染下一次任务:一轮任务的 todo 全部完成后,新任务不会带着上一轮的续跑上下文。

    v0.1.63 (2026-07-15)¶

    Features¶

    • 编辑器体验全面改进(PR #25):tab 右键菜单 / 中键关闭 / 拖拽排序 / 关闭其他·右侧·全部、Alt+方向键前进后退导航、Ctrl+P 最近打开(独立 MRU 文件历史)、头文件 Ctrl+click 跳转、切换 tab 保存并恢复光标·滚动·折叠·选区、编辑器偏好面板(tab / 换行 / minimap 等)接通 Monaco。
