    Editor¶

    Activity bar → Core → Editor. File tree on the left, tabbed editing area on the right.

    Keyboard shortcuts¶

    These are the shortcuts the application actually binds.

    Some entries in the in-app shortcut panel are placeholders

    Ctrl+N (new file), Ctrl+O (open project), Ctrl+Shift+S (save all) and Ctrl+, (settings) are listed in that panel but are not wired up — pressing them does nothing. Only the working ones are listed below.

    Files¶

    Action Shortcut
    Quick open by filename Ctrl+P
    Save Ctrl+S

    These have no shortcut; use the UI instead:

    • New file / folder — right-click a directory in the file tree
    • Open project — the project-name dropdown in the toolbar, or the welcome screen
    • Settings — the gear icon at the top right

    Editing and view¶

    Action Shortcut
    Undo / Redo Ctrl+Z / Ctrl+Shift+Z
    Find / Replace Ctrl+F / Ctrl+H
    Global search Ctrl+Shift+F
    Toggle sidebar Ctrl+B
    Split editor Ctrl+\
    Toggle comment Ctrl+/

    Navigation¶

    Action Shortcut
    Back / Forward (previous, next location) Alt+Left / Alt+Right
    Go to definition F12
    Symbol search Ctrl+T
    Close tab Ctrl+W
    Reopen closed tab Ctrl+Shift+T

    AI¶

    Action Shortcut
    Show / hide the AI assistant Ctrl+J
    Focus the input box Ctrl+K
    New session Ctrl+L
    Toggle Plan mode Ctrl+Alt+P
    Stop the current answer Esc
    Inline AI chat (with code selected) Ctrl+I

    Ctrl+B is not Build

    It toggles the sidebar, as in VS Code. Build from the toolbar, or just ask the AI to compile.

    File tree¶

    Shows the project directory. Right-click a file or folder to create a file, create a folder, rename or delete. (Drag-and-drop moving is not supported yet — rename, or move the file outside the app and refresh.)

    There is no directory-level write protection

    Vendor directories such as ARM/System, Drivers and FW can be edited and saved like any other file, and the tree shows no read-only marker. Take care not to edit HAL sources by accident.

    "Vendor directories are read-only" is a convention for the AI assistant, not editor write protection: layered skeleton projects created by EmbAI record vendor_dirs_readonly in .embai/config.json and the AI is told not to touch them. Projects migrated from Keil don't get that field, but the AI is likewise told to confirm with you before changing vendor libraries.

    Tabs and splitting¶

    Ctrl+\ splits the editor so you can compare two files side by side. Ctrl+W closes the current tab and Ctrl+Shift+T brings it back.

    Global search¶

    Ctrl+Shift+F opens the search panel for project-wide text search with file filtering.

    Symbol navigation¶

    F12 jumps to a definition; Ctrl+T searches by symbol name. Alt+Left returns to where you were.

    Inline AI chat¶

    Select a block of code in the editor, then press Ctrl+I (or pick "Inline Chat" from the context menu). An input box appears above the selection, letting you make a request about just that code ("switch this to DMA", "add error handling").

    Selecting code alone does not open it — the shortcut or context menu is required.

    • Tab accepts the change
    • Esc discards it

    This path does not consume the session in the right-hand AI panel, which makes it good for small edits. For larger changes prefer the AI panel, where you can watch the tool calls.

    Save-conflict protection¶

    If a file has been edited in the editor while something else (Keil, or the AI) also changed it on disk, saving detects the conflict and warns instead of overwriting.

    The same applies to building: pressing Build first saves all unsaved tabs, and if a conflict shows up the build is aborted with a prompt — so you never compile stale code by accident.

    Editor preferences¶

    Theme and editor font size live under Settings → General (which also has language, autosave interval, file encoding and system notifications).

    Line numbers, tab size, word wrap and the minimap belong to "Editor preferences", a panel that currently has no UI entry point.
