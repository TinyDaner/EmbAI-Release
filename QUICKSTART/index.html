    快速上手¶

    从零到烧录成功。全程大约 20 分钟，其中一大半是等 Keil 和固件库下载。

    1. 先装两样 EmbAI 不自带的东西¶

    必需 说明
    Keil MDK 固件编译只走 Keil 的 UV4.exe。EmbAI 不内置编译器。
    J-Link 驱动 默认的烧录与调试路径。用 ST-Link 或 DAPLink 的话见安装与环境。

    另外第一次建工程需要联网：HAL/CMSIS 固件库要从 GitHub 上的 STM32Cube 仓库现下。

    装法与排错见安装与环境。

    2. 装 EmbAI 并登录¶

    1. 从 Releases 页面下载 Windows 安装包，装完启动。
    2. 登录页只有一个按钮：通过浏览器登录 / 注册。点它会打开系统浏览器， 在网页上完成注册或登录后自动跳回应用。

    为什么是浏览器登录

    账号、AI 额度和积分都在云端统一管理，走浏览器可以复用已登录的 GitHub / Google / 微信，也避免应用里出现密码输入框。详见账户与积分。

    3. 确认环境已就绪¶

    设置（右上角齿轮）→ 编译器 → 打开环境检测。

    Keil 和 J-Link 两行应该显示为已安装。如果标红，点该行的配置路径手动指到 UV4.exe 或 JLinkARM.dll 所在位置。

    这一步别跳过

    Keil 没配好的话，直到你点「构建」才会报错： 未找到 Keil UV4.exe。请在「环境检测」中配置 Keil 路径……

    4. 新建工程¶

    欢迎页点新建项目（或工具栏的新建），走 6 步向导：

    步骤 选什么
    1. 芯片 按系列筛选或直接搜型号，787 颗 STM32 任选
    2. 固件库 HAL / LL / HAL+LL / SPL，可指定 Cube 固件包版本
    3. RTOS 裸机 / FreeRTOS / RT-Thread / CMSIS-RTOS
    4. 外设与中间件 UART、SPI、I²C、TIM、ADC、DMA 逐项展开配置
    5. 工具链与调试器 默认 Keil + J-Link + SWD + 4000 kHz
    6. 名称与路径 再勾选示例代码、Git 初始化、单元测试、Doxygen

    点完成后先别急着编译：看状态栏，固件库正在从 GitHub 下载，进度条走完才算就绪。 下载失败时状态栏会给一个重试按钮。

    没等库下完就编译

    会被挡下并提示「固件库尚未就绪……请等待固件库下载完成」。这不是 bug， 是防止你拿着缺 HAL 头文件的工程编译半天。

    5. 让 AI 写业务代码¶

    向导只生成能编译的工程基座。工程建好后 AI 面板会自动打开，并开始逐项反问你的需求 （要点什么灯、用哪个串口、波特率多少），然后一个文件一个文件地生成代码。

    这就是 EmbAI 的主线用法 —— 不必自己从 main.c 空文件开始写。

    想先看它打算怎么做，可以开 Plan 模式（输入框左侧 + → 计划模式，或按 Ctrl+Alt+P）：AI 会先交一份计划等你批准，再动手。

    6. 编译¶

    工具栏点构建。底部面板会自动切到构建输出，实时显示 Keil 的编译日志， 末尾是 N Error(s), M Warning(s)。

    有报错就直接在 AI 面板里说「修一下编译错误」—— 它能读到构建输出。

    7. 接板子，烧录¶

    接好调试器，工具栏点构建并烧录。会弹出进度对话框，依次走擦除 → 写入 → 校验。

    • J-Link 没连的话 EmbAI 会自动连接，目标芯片取自工程配置。
    • 提示未找到固件，请先构建项目说明还没编译成功过。
    • 提示自动连接失败一般是板子没供电、调试口被锁，或者选错了接口/速率。

    烧录成功后对话框上有个打开串口按钮，可以直接进下一步。

    8. 看输出¶

    底部面板 → 串口助手 → 选端口和波特率连接。支持 HEX 视图、时间戳、收发字节计数。

    如果你的固件是在往外吐数值而不是文本，试试活动栏的 超级串口 —— 拖几个波形和仪表出来，比盯着一屏数字直观得多。 详见串口与超级串口。

    常见卡点¶

    现象 原因与处理
    点「构建」提示找不到 UV4.exe Keil 没装或路径没配。设置 → 编译器 → 打开环境检测 → 配置路径
    提示「请先打开项目」 当前没有打开的工程，先新建或打开一个
    提示固件库尚未就绪 等状态栏进度条走完；失败就点状态栏的重试
    固件库一直下不动 需要能访问 GitHub。换网络或配代理后点重试
    烧录提示自动连接失败 检查供电与接线；换 SWD/JTAG 或降低速率再试
    编译器设置里填了 GCC / CMake 路径但没反应 固件编译只用 Keil，这两项当前不参与固件构建
